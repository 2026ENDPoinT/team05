# POLARIS · Academic Navigator (북극성)

대학생을 위한 성적 관리 및 학사 의사결정 지원 웹서비스 (Python + Flask)

## 실행 방법
1. Python 3.10 이상 설치 (python.org에서 설치할 때 "Add Python to PATH"에 체크)
2. 이 폴더에서 터미널(명령 프롬프트)을 열고 아래를 차례로 입력
   ```
   pip install -r requirements.txt
   python app.py
   ```
3. 브라우저에서 http://127.0.0.1:5000 접속 (끝낼 때는 터미널에서 Ctrl + C)

## 폴더 구조
| 파일 | 역할 |
|---|---|
| `calc.py` | 핵심 계산 알고리즘 (성적 추정, 시나리오, 철회, 재수강, 졸업 부담) |
| `rules.py` | 학교 규정 기준값 모음. 예시값은 학칙을 확인하고 여기서 수정 |
| `app.py` | Flask 서버. 화면의 요청을 받아 calc.py를 호출 |
| `importer.py` | 엑셀/CSV 파일에서 지난 학기 성적 읽기 |
| `storage.py` | SQLite(`data/gradepath.db`)에 브라우저(쿠키)별로 저장·불러오기, 시작할 때 예전 JSON을 한 번 이전 |
| `templates/index.html`, `static/` | 화면 |
| `tests/test_calc.py` | 계산 검증 (`python tests/test_calc.py`) |
| `tests/test_importer.py` | 불러오기 검증 (`python tests/test_importer.py`) |
| `tests/test_storage.py` | 저장·이전 검증 (`python tests/test_storage.py`) |

## 계산 방식 요약
- 예상 학점: z점수 = (내 점수 - 평균) ÷ 표준편차 → 정규분포로 상위 % 계산 → 상대평가 비율표로 학점 결정
- 출석·과제 포함(선택): 시험·출석·과제 점수를 반영 비율로 가중 평균한 점수로 위 계산을 수행 (비율 합이 100% 미만이면 입력한 항목끼리 비율을 다시 맞춤)
- 예상 학점 범위: 사용 시점별 변동 폭(중간고사 이후 ±0.6, 기말고사 이후 ±0.15 표준편차, 임의 설정값)만큼 z점수를 움직여 최저~최고 학점 산출
- 목표 달성 가능성: 점수 변동을 3000번 무작위로 뽑아 누적 평균 학점이 목표 이상인 비율로 높음/보통/낮음 표시 (검증된 확률 아님)
- 학기 평균 학점(이번 학기 과목만)와 누적 평균 학점(전체)를 구분해 표시
- 계절학기: 설정에 입력한 계획 학점만 졸업 잔여 학점에서 차감 (최대 가능 학점 자동 차감 없음)
- 평점평균 = (학점 × 평점)의 합 ÷ 학점의 합, 취득 학점은 F·P/F 과목 불합격 제외
- P/F(합격/불합격) 과목: 합격(P)은 학점만 취득하고 평균 학점에서 제외, 불합격(F)은 평균 학점에서 제외되고 학점 미취득 (재수강 비교 미지원). 일반 과목의 F는 평점 0으로 계산. 내부 값은 P/NP로 저장
- 재수강: 새 성적이 예전 성적을 대체하고 상한을 넘지 못한다고 가정

## 꼭 확인할 것
- 학칙 확인됨: A0 이상 30% 이하, B0 이상 70% 이하, C+ 이하만 재수강 가능, 재수강 최고 성적 A0, 총 졸업 130·전공 70학점(2017학번 이후 기준, 본인 입학년도 확인)
- 확인됨: 누적 A+ 15%, A0 30%, B+ 50%, B0 70%
- 학교 홈페이지 확인(2017학번 이후 입학): 학기당 최대 19학점, 학년도 37학점, 직전 학기 평균 학점 3.75 이상·12학점 이상 취득 시 +3학점(그 학기에만), 계절 등 포함 1년 최대 48학점 (2016학번 이전은 21/40/+4(15학점)/52)
- 예시값: C 이하 세부 비율, 절대평가 기준 점수, 'A 비율 완화' +10%p, 점수 변동 폭

`rules.py`와 설정 탭에서 수정할 수 있습니다.


## 알려진 한계 / 앞으로 할 일
- 출석·과제는 선택 입력, 기말고사는 반영 비율만 입력하면 "몇 점이면 어떤 학점"을 표로 보여 줌(기말 반 평균·표준편차는 중간고사와 같다고 가정): 체크하면 반영 비율(%)로 시험 점수와 가중 평균해 하나의 점수로 계산. 출석·과제의 반 평균·표준편차는 모르므로 예시값(rules.py)을 가정
- 로그인이 없어 데이터는 브라우저별로 분리됨 (다른 기기와 공유 불가)

## 저장소 (SQLite)
- 테이블: `users`(uid, 사용방법 확인 여부), `settings`, `completed_courses`, `current_courses`, `migrated_files`
- 예전 `data/users/*.json`은 서버 시작 시 한 번만 DB로 옮기며, JSON 파일은 지우지 않습니다.
- DB 직접 확인 (파이썬만으로):
  ```
  python -c "import sqlite3; c=sqlite3.connect('data/gradepath.db'); print(c.execute('select uid, name, grade from completed_courses join users using(uid)').fetchall())"
  ```
  (`sqlite3 data/gradepath.db` 명령이 있으면 `.tables`, `select * from completed_courses;`)

## 스프레드시트로 성적 불러오기
- '내 성적' 탭 → '스프레드시트에서 불러오기'에서 .xlsx 또는 CSV 파일을 올립니다. '양식 받기'로 예시 파일을 받을 수 있습니다.
- 첫 줄 칸 이름: 학기, 과목명, 학점, 구분(전공/교양, 전공필수·교양필수도 인식), 필수, 성적(A+ … F, P/F 과목은 P 또는 불합격). 칸 이름 별칭도 일부 인식합니다.
- 저장 전에 미리 보기로 확인하고, 이미 있는 과목(학기·과목명·학점·성적이 같음)은 제외합니다. 오류가 있는 줄은 줄 번호와 함께 알려 주며 불러오지 않습니다.
- 첫 번째 시트만 읽고, 파일은 1MB·200줄까지입니다. 업로드한 파일 자체는 저장하지 않습니다.
- 엑셀을 읽으려면 `openpyxl`이 필요합니다 (`pip install -r requirements.txt`에 포함).


## 계산과 설명의 분리 (AI 사용 방식)

- **숫자는 코드가 계산합니다.** 환산 점수, 기말고사 시나리오, 목표 학점까지 필요한 기말 점수(역산), 학기별 권장 학점은 모두 `calc.py`가 계산합니다. 같은 입력이면 항상 같은 값이 나옵니다 (모의 계산도 난수 시드 고정).
- **AI(LLM)는 문장만 만듭니다.** `llm.py`가 계산이 끝난 숫자를 받아 '취약점'과 '보완 방법' 문장으로 풀어 씁니다. 숫자를 새로 계산하지 않습니다.
- 환경변수 `ANTHROPIC_API_KEY`(필요하면 `GRADEPATH_MODEL`)를 설정하면 AI 문장, 없거나 실패하면 같은 숫자로 규칙 기반 문장을 보여 줍니다. 서버로 보내는 값은 과목명과 점수 숫자뿐입니다.

## 기말고사 예측과 그래프

- 입력: 중간고사 점수·반 평균·표준편차, 항목별 반영 비율(중간·기말·퀴즈·과제·출석 등)과 지금까지 점수. 기말고사는 점수를 모르므로 비율만 입력합니다.
- 출력: 지금까지 환산 점수, 기말 시나리오(최소·낮음·평균·높음·최대), 목표 학점에 필요한 기말 점수(역산).
- 그래프(`static/charts.js`, SVG 직접 그림): 기말 점수별 환산 총점 + 반 평균선 + 예상 범위 띠 + 목표 기준선을 한 차트에 겹쳐 표시, 과목별 레이더 차트(과목 3개 미만이면 막대), 학기별 평균 학점 추이 선 그래프.
- 그래프 데이터는 `/api/chart-data`(JSON), `/api/chart-data?format=csv`(CSV)로 내려받을 수 있어 발표 자료에도 쓸 수 있습니다.
- 퀴즈·과제·출석 항목의 반 평균·표준편차는 알 수 없어 예시값(`rules.py`)을 가정하고, 기말고사는 중간고사와 같은 평균·표준편차로 가정합니다.

## 학업 가이드

- '학업 가이드' 탭: 전체·전공 학점 진행 막대, 이번 학기 이후 학기별 권장 이수 학점과 전공/교양 배분, 졸업 부담, 수강 철회·재수강 분석으로 이동.
- 학기 번호는 설정의 '남은 정규 학기 수'로 계산하고(8 - 남은 학기 = 이번 학기), 권장 전공 학점은 남은 전공 학점을 남은 학기에 고르게 나눈 평균값입니다. 실제 개설 과목과 선후수 관계는 학과 교육과정에서 확인해야 합니다.

## 만점이 다른 시험 (점수 환산)

- 중간고사·기말고사·퀴즈·과제 등 모든 항목에 만점을 따로 입력할 수 있습니다. 비워 두면 100점 만점입니다 (예전 데이터도 그대로 동작).
- 내부에서 환산 점수 = 입력 점수 x (100 / 만점)로 바꿔 계산합니다. 중간고사의 평균·표준편차도 같은 비율로 환산합니다. (예: 만점 35, 점수 27, 평균 21.02, 표준편차 6 -> 77.14 / 60.06 / 17.14)
- 기말고사 결과 표는 기말 만점 단위로 보여 줍니다 (표시 점수 = 100점 기준 점수 x 기말 만점 / 100). 환산 총점과 예상 학점은 내부 100점 기준으로 계산합니다.
- 점수가 만점을 넘으면 "값은 N 이하여야 합니다"라는 경고가 나옵니다.

## 학업 가이드: 바쁜 학기를 고려한 학점 배분

- 학업 가이드 탭에서 취업 준비 등으로 바쁜 학기를 고르면, 남은 학점을 세 가지 방식으로 나눈 배분안을 비교할 수 있습니다 (기본값은 4학년 학기).
  - 균등형: 모든 정규 학기에 고르게
  - 균형형: 바쁜 학기는 다른 학기의 절반 비중으로
  - 최소형: 바쁜 학기를 졸업에 꼭 필요한 최소 학점으로 (나머지 학기는 한도에 가깝게)
- 학기당 최대 학점과 학년도 최대 학점(두 학기 합)을 지키며, 졸업에 정규 학기만으로는 학점이 모자라면 부족한 학점을 알려 줍니다.
- 숫자는 모두 `calc.life_guide`가 계산하고(같은 입력이면 같은 값), '배분안 설명 보기'의 문장만 `llm.explain_guide`가 씁니다. API 키가 없거나 실패하면 규칙 기반 문장을 보여 줍니다. 과목 추천은 하지 않습니다(개설 과목을 모르기 때문).


## 배포하기 (인터넷에서 누구나 접속하게 만들기)
해커톤처럼 심사자가 주소만 눌러서 바로 써 볼 수 있으면 유리합니다. 이 폴더에는 배포용 파일(`Procfile`, `render.yaml`, `requirements.txt`의 gunicorn)이 이미 들어 있습니다.

### 방법 A. Render (무료, GitHub만 있으면 됨)
1. 이 폴더를 GitHub 저장소로 올립니다 (`data/*.db`는 `.gitignore`로 제외됨).
2. render.com 가입 → New → **Blueprint** → 저장소 선택 → 만들어지면 `https://polaris-xxxx.onrender.com` 같은 주소가 생깁니다.
3. (선택) AI 설명 문장을 쓰려면 서비스의 Environment에 `ANTHROPIC_API_KEY`를 넣습니다. 없어도 기본 문장으로 동작합니다.
- 무료 플랜은 15분 동안 접속이 없으면 잠들어 첫 접속이 30~60초 느리고, 저장 디스크가 없어 **서버가 다시 켜지면 입력한 데이터가 사라질 수 있습니다.** 심사 직전에 주소를 한 번 열어 깨워 두세요.

### 방법 B. PythonAnywhere (무료, 데이터가 유지됨)
1. pythonanywhere.com 가입 → Files에서 이 폴더 업로드 → Bash 콘솔에서 `pip install --user -r requirements.txt`
2. Web → Add a new web app → Flask → 소스 경로를 이 폴더로, WSGI 파일에서 `from app import app as application` 로 지정
3. 주소는 `https://아이디.pythonanywhere.com` 입니다. (무료 계정은 외부 사이트 접속이 제한되어 AI 문장은 기본 문장으로 동작)

### 배포 때 알아둘 점
- 환경변수: `PORT`/`HOST`(서버 주소, 배포 서비스가 자동 지정), `POLARIS_DATA_DIR`(DB 저장 폴더), `ANTHROPIC_API_KEY`(선택)
- 로그인이 없어 데이터는 접속한 브라우저(쿠키)별로 분리됩니다. 심사자가 입력한 데이터가 서버에 저장되니, 화면 아래 안내 문구를 지우지 마세요.
- 배포 서버 확인용 주소: `/healthz`
